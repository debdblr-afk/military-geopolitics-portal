## 🚀 How to Host on Cloudflare Pages (100% Free)

### Step 1: Connect GitHub Repo in Cloudflare
1. Log in to your [Cloudflare Dashboard](https://dash.cloudflare.com/) (free tier).
2. In the left navigation, click **Workers & Pages** → **Create application** → **Pages** tab.
3. Select **Connect to Git** and choose your repository: `debdblr-afk/military-geopolitics-portal`.
4. Click **Begin setup**.

### Step 2: Configure Build Settings
Fill in the build configuration:
- **Project name**: `iskander-portal` (or your choice)
- **Production branch**: `main`
- **Framework preset**: `Astro`
- **Build command**: `npm run build`
- **Build output directory**: `dist`
- **Environment variables**:
  - `NODE_VERSION` = `20` (or `22`)
  - `ASTRO_TELEMETRY_DISABLED` = `1`

Click **Save and Deploy**. Cloudflare Pages will build the site and deploy it globally in under 60 seconds!

## 🌐 How to Add Custom Domain `iskander.dbdd.in`

Once the project is deployed on Cloudflare Pages:

1. In the Cloudflare Pages project dashboard, click the **Custom domains** tab.
2. Click **Set up a custom domain**.
3. Enter your domain: `iskander.dbdd.in` and click **Continue**.
4. **DNS Setup**:
   - If your root domain `dbdd.in` is already managed on Cloudflare DNS:
     Cloudflare will automatically add the CNAME record for you with one click.
   - If your DNS is managed with an external registrar (e.g. GoDaddy, Namecheap, Google Domains):
     Add the following DNS record in your DNS provider's dashboard:
     ```
     Type:  CNAME
     Name:  iskander
     Value: <your-cloudflare-pages-project>.pages.dev
     TTL:   Auto (or 300)
     ```
5. Cloudflare will automatically provision a free universal SSL/TLS certificate for `iskander.dbdd.in` within minutes.
